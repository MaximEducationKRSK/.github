# MaximEdu

**Образовательный проект для школьников и абитуриентов Красноярска.**

Интерактивная карта учебных заведений: школы, колледжи, университеты.
Помогает выбрать учебное заведение по району, специализации и рейтингу.

## 🎯 О проекте

MaximEdu — это веб-приложение, которое помогает:
- 🏫 Найти школу, колледж или вуз в Красноярске
- 📊 Сравнить по рейтингу и специализации
- ❤️ Сохранить избранное
- 🗺️ Посмотреть расположение на карте

## 📊 Что внутри

| Тип | Количество |
|---|---|
| 🏫 Школы | 29 |
| 📚 Колледжи | 19 |
| 🏛️ Университеты | 18 |
| **Всего** | **66** |

---

## 🛠️ Технологии

- **Frontend:** HTML, CSS, JavaScript
- **Карты:** Leaflet + OpenStreetMap
- **Геокодинг:** DaData
- **Backend:** ASP.NET Core

Единое цифровое пространство: заметки, расписание, задачи, файлы, карты, учебные материалы и совместная работа в реальном времени.

##🎯 О проекте

MaximEduBoard — это веб-приложение, которое помогает:

📝 Вести заметки и конспекты прямо в браузере

📅 Планировать расписание, дедлайны и задачи

📂 Хранить файлы, учебники и материалы

🗺️ Открывать интерактивную карту учебных заведений

👥 Работать над доской вместе с одноклассниками и друзьями

🔎 Искать всё — от формул до адресов — в одном окне
